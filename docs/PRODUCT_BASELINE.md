# 晴天专属支付中心｜产品基线

本文件是项目长期产品边界与技术基线。后续功能在此基础上迭代，不因临时预览页面而另起一套。

## 产品定位
- 仅服务晴天本人旗下多个网站和业务，不开放第三方商户入驻。
- 支付中心独立部署；各业务网站通过独立的 site_id 和 API 凭证接入。
- 各网站的商品、订单、支付、退款、交付数据必须按 site_id 隔离。
- 首期支付渠道为支付宝官方接口；支付密钥只保存在 Cloudflare Secrets，不进入 Git。
- GitHub Pages 仅用于源码构建检查/临时界面查看，不是生产运行环境。
- 生产目标：Cloudflare Workers + D1；先完成代码、迁移、测试和验收，再部署。不得连接旧项目的生产 D1。

## 固定技术边界
- Web 管理端：React + Vite。
- 服务端：Cloudflare Worker API（模块化路由）。
- 数据库：本项目独立 D1，所有业务表以 site_id 隔离。
- 认证：服务端验证；密码使用 Argon2id 等安全哈希；HttpOnly、Secure、SameSite 会话 Cookie；登录限流；审计日志。
- 权限：固定超级管理员名单由服务端强制保护，不能通过普通管理接口删除或降权。
- 支付：服务端创建订单、调用支付宝官方接口、验签异步通知、主动查询补偿；不得仅凭前端回跳判定支付成功。
- 退款：记录申请、渠道退款请求、渠道结果及操作审计。
- 交付：支付成功后按业务站点配置执行交付；保留交付状态、重试记录和幂等键。

## 管理模块（正式范围）
1. 总览与统计
2. 业务网站与 API 凭证
3. 商品管理
4. 订单管理
5. 支付渠道与支付记录
6. 退款管理
7. 自动交付与交付记录
8. 管理员、角色与会话
9. 系统设置、操作审计与安全事件

## 数据隔离和安全规则
- 所有业务数据读写必须从已认证的站点上下文取得 site_id，不能信任客户端传入的 site_id。
- API 凭证只存哈希；创建时只展示一次。
- 支付宝私钥、应用密钥、证书等只用 Cloudflare Secrets/受保护配置。
- 禁止将用户密码、密码哈希、支付密钥或会话令牌提交到仓库。
- 订单号、支付通知和交付操作均需幂等处理。
- 管理操作必须写入审计日志。

## 当前阶段与验收原则
当前仓库只有前端起始界面和开发中的导航骨架，尚无真实认证、Worker API、D1 绑定或支付宝支付能力。不得将任何静态界面标记为已完成模块。

正式验收必须逐项通过：真实登录/退出、权限拒绝测试、跨站点数据隔离测试、订单创建、支付宝验签与支付状态同步、退款闭环、交付幂等与失败重试、审计日志、移动端适配和生产构建。
